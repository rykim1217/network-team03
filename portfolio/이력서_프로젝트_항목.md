# 이력서 프로젝트 항목 초안

## EngineSquare 보안 관제 및 SOAR 자동 대응 시스템

- 기간: `[정확한 시작일] ~ [정확한 종료일]`
- 역할: 보안 이벤트 수집·탐지·자동 대응 파이프라인 검증 및 n8n 알림 연동 정리
- 기술: Python, Flask, FastAPI, MySQL, Docker, SQLite WAL, Graylog, Wazuh, n8n, pfSense, Discord Webhook
- 핵심 내용: 브루트포스 IP 차단, 유출 API 키 폐기·재발급, 3단계 킬체인 상관분석 및 대응
- 성과:
  - 2만 건 로그 스파이크에서 최종 queue lag 0, dropped 0, DLQ 0 확인
  - 시나리오 1 브루트포스와 시나리오 3 CRITICAL/WARNING 분기 재현
  - n8n Discord 알림을 개인 채널 Incoming Webhook 방식으로 통일하고 저장소 민감정보 제거
  - 루트 API 테스트 14건 통과

### 한 줄 버전

Graylog·Wazuh·n8n·pfSense를 연결한 보안 관제 프로젝트에서 로그 버퍼링, API 키·IP 자동 차단, 킬체인 대응을 개인 환경에서 재현하고 운영 문서와 민감정보 관리 체계를 정리했습니다.
